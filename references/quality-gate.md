# 输出前质量检查

在内部检查并改稿，不把检查表附在默认输出后。先排硬矛盾，再改善审美和信息密度。

## 七个维度

| 维度 | 需要的证据 |
|---|---|
| 完整性 | 人物、场景、时间线、画面、表演、声音和结尾齐全，每个复制块独立可用 |
| 因果关系 | 转折有可感知刺激，角色知情不越界，动作带来后果，补充未改变故事核心 |
| 镜头调度 | 起点、朝向、运动动机、终点清楚；路径可达，切镜与景别能展示关键信息 |
| 人物表演 | 行为服务具体目标；听者有反应，微动作可见，情绪过渡有时间和原因 |
| 声音设计 | 声源、方位、距离、进入与结束明确；声画节奏和跨切一致 |
| 连续性 | 身份、衣物、道具、持物手、光源、风向、轴线、动作状态衔接 |
| 可执行性 | 时间和对白容量合理；分段适配已知限制；没有互斥参数、虚构素材或能力保证 |

硬失败包括：遗漏用户指定事件或更改结局、指定中文却默认英文、指定非欧美背景却被改写、不存在的参考图、道具无交接换手、已完成动作再次从初态发生、相机穿越障碍、不可见动作承担唯一叙事信息、连续时间轴断裂或超时、复制块超过已知上限、把多个独立段伪称已实现真正一镜到底。

核对取景下缘与动作最低点：需要看见箱体、袋口或脚步时，景别必须确实覆盖它。把画外追赶者也纳入起始距离、速度和到达时刻的预算，不能只核对主角与摄影机。

发现硬失败先修，不能用文采、品牌参数或高自评分抵消。时间不足时先删次要台词和动作，再重排；不能悄悄延长用户明确指定时长。

## 对照改进方法

“约 30%”是七维综合改善的目标，不是预先保证的分数或成片指标。需要评估时，固定同一句故事线、相同时长和约束，对原写法与技能输出做成对比较。每项 0–4 分：0 缺失／严重矛盾，1 有描述但无法执行，2 基本成立且有明显遗漏，3 完整自洽，4 能指出具体叙事和执行上的优势。

记录评分理由与段落证据。只有基线确实存在、评分过程实际进行且基线非零时，才可计算相对变化；高基线受满分约束，不能为了达到 30% 压低旧稿分数。自评只说明内部审查，不构成独立盲评。实际视频的提升需要同模式、同预算的成片对照。

可验证的近期改善是：原稿明确缺陷是否修复，七维是否缺项，时长和段落衔接是否通过，遇到新故事及用户覆盖要求是否仍然正确。未进行成片测试时明确记录“文本验证”，不写“视频测试通过”。

## 时间核对工具

`scripts/audit_timing.py schedule.json` 检查连续片段、总时长、对白窗口及英语语速预算。输入规范见脚本 `--help`；示例见 `evals/timing-pass.json`。它只核对输入时间表，不能保证表与提示词一致，也不能验证人物几何、艺术质量或生成结果，必须人工对照最终稿。

最终通读时让每镜在脑中连续播放一次，尤其审查结尾是否还容得下动作、呼吸和声音尾巴；不要只检查标题是否齐全。
