# 验证记录

验证对象：`one-shot` 首版。范围是技能结构、源材料提炼、提示词文本和时间表工具；没有调用即梦生成视频，没有进行成片或音频实测。

## 来源与结构

- 实际使用十三份 DOCX，均完成正文提取和审阅。原计划缺少的 DOCX 和 Markdown 未纳入，也未用外部材料代替。
- 来源文件名、正文字符数和文件摘要见 [来源索引](source-index.json)；具体提炼与修正见 [方法来源](../references/source-distillation.md)。不分发原件或用户个人文件路径。
- 使用 Codex skill-creator 的 `quick_validate.py`，技能格式校验通过。该检查只证明格式与基础结构有效，不证明电影质量。

## 新故事试用

由未读取原始 DOCX、作者工作上下文或现有示例的独立测试代理，仅根据技能与参考指南完成三项任务。测试代理生成后自行审查修订，主作者再审阅最终稿。这是独立使用与复核，不是双盲评价。

| 输入类型 | 最终样例 | 观察结果 |
|---|---|---|
| 一句话：退休列车司机在末班车站台遇见多年未见的女儿 | [留给你的那段路](../examples/last-train.md) | 自选 30 秒，两个独立 15 秒段，中文正文、英文对白、英国人物；有辨认、试探与同行的因果变化 |
| 指定 15 秒、一镜到底：女人提着沉重旅行袋穿过街市，听见追赶声后转入小巷 | [左转](../examples/luggage-chase.md) | 保留时长、单镜、负重、听见后反应及进入小巷；右手和袋子状态连续；相机实际走过转角 |
| 指定日本人物、全部中文对白、15 秒、多镜头：父亲在校门接不愿回家的女儿 | [再等一会儿](../examples/override.md) | 国家与语言分别覆盖默认值；中文台词、镜头与时长要求保留；结尾仍是陪女儿等待 |

三篇时间段总和分别为 30、15、15 秒，分段均连续；对话窗口及字词计数见 [时间证据](forward-timing.json)。英文约 1.25–2 个词/秒；中文按场景人工核对，约 2.35–2.73 字/秒。字词速度只是容量估算，不能代替发声测试。

审查中真实发现并修订了：对话词数标注错误、景别没有覆盖完整箱体或大衣袋口、相机提前进入小巷、追赶者初始距离不足，以及父亲朝向含混。最终示例已修订；质量指南补充了“取景下缘覆盖动作”和“画外角色也计入位移预算”。

[厚涂示例](../examples/painter.md) 是作者编写并检查的风格样例，未计入上述独立试用。它示范左手、画中变化与现实变化的因果顺序。

## 时间工具

实际运行九项断言，全部符合预期：[结果](timing-test-results.json)。覆盖连续时间线、缺秒、结尾不足、英语对白超载、未声明的重叠对白、允许的两人重叠、同一人同时说两句、中文需要人工语速复核，以及非有限数值拒绝。正常样例可重跑：

```bash
python3 scripts/audit_timing.py evals/timing-pass.json
```

工具只检查提供的 JSON 时间表。提示词与时间表是否一致、画外人物位置、机位可达性、表演和成片质量仍需审查。
